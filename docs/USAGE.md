## 2. 安装 / 卸载

### 图形界面安装

1. 完全退出要安装的游戏。
2. 运行 `ColoringVoxelsTool-Setup-vX.Y.Z.exe`。
3. 安装器会自动检测目录；若检测失败可点「浏览」手动选择**包含 `ColoringVoxels.exe`** 的那一层目录。
4. 点击「一键安装」，等待进度条完成。
5. 安装完成后游戏会自动启动（可在「安装选项」里关闭）。

落地文件：`winhttp.dll`、`BepInEx\`（含 `plugins\ColoringVoxelsTool.dll`）。

### 静默安装（脚本化）

```powershell
# 静默安装到指定目录，不启动游戏
.\ColoringVoxelsTool-Setup.exe --silent --dir="C:\Program Files (x86)\Steam\steamapps\common\Coloring Voxels" --no-launch

# 只检测游戏目录
.\ColoringVoxelsTool-Setup.exe --detect-only
```

退出码：`0` 成功，`1` 失败，`2` 目录无效，`3` 游戏正在运行。

### 卸载

- 重新运行安装器 → 点「卸载」；
- 在弹出的卸载对话框中可选：
  - **还原安装时备份的文件**（默认勾选）；
  - **同时移除 BepInEx 本体**：连 `winhttp.dll`、`BepInEx/` 一起删除。

命令行卸载：

```powershell
.\ColoringVoxelsTool-Setup.exe --uninstall --remove-bepinex
```

注意：卸载会移除工具文件（含 `BepInEx\config`），但**不会**触碰
`%APPDATA%\ColoringVoxelsTool` 里的等级与经验存档。

### 手动安装（不使用安装器）

1. 打开仓库的 `vendor/bepinex-x64/`，把其中**全部内容**复制到游戏目录。
2. 用 `installer/payload/doorstop_config.ini` 覆盖游戏目录下的同名文件。
3. 把 `artifacts/ColoringVoxelsTool.dll` 复制到 `<游戏目录>\BepInEx\plugins\`。
4. 启动游戏。

### 3.1 插件（《Coloring Voxels》）

| <kbd>F1</kbd> | 打开 / 关闭面板 |

## 4. 面板说明

进入关卡后按 <kbd>F1</kbd> 打开面板。3D 版面板为**单页、可滚动**，从上到下分区：

### 4.1 关卡

显示世界 / 关卡、当前层、当前颜色、剩余体素，以及一条总进度条。

### 4.2 预览（当前层）

当前这一层的整层缩略图，直接读游戏的体素数据（目标色 + 已涂色 + 颜色表），不是截图：

- 已涂的格子显示真彩，没涂的显示压暗的「底稿」（可用开关关掉）；
- 只画当前选中的那一层（游戏一次也只让你涂这一层）。

### 4.3 自动完成

| 功能 | 说明 |
| --- | --- |
| 一键涂完本层 | 立即把当前层的待涂体素涂满（<kbd>F2</kbd>） |
| 拟人涂色 | 逐层推进，层内按颜色分块 + 蛇形扫行，带手速抖动与随机停顿（<kbd>F3</kbd>） |
| 立即保存 | 立刻写盘（<kbd>F5</kbd>） |
| 手速 | 每秒涂多少格（滑条 5–220） |
| 只涂当前颜色 | 只处理调色板里高亮的那一种颜色 |

拟人算法要点：一层一层往上涂 → 同一层按颜色分组 → 同色体素**就近分块** → 块内**蛇形扫行**生成笔顺 → 按手速推进、每「笔」后按概率停顿。落笔调用游戏自己的涂色逻辑，所以计数与存档和手涂一致。

### 4.4 自动化

| 参数（对应配置项） | 说明 | 默认 |
| --- | --- | --- |
| 总时长分钟 | 自动化任务的总运行时间 | 30（1–480） |
| 连续涂图 | 涂完当前图后自动切下一张 | 关 |
| 换图间隔秒 | 完成一张图后到切下一张的等待 | 3（0.5–30） |
| 涂色速度预设 | 0 = 自定义（用下面三项）；1 慢 / 2 中 / 3 快 | 1 |
| 自定义手速 / 笔触 / 停笔 | 预设选「自定义」时生效 | 60 / 40 / 0.3 |

三档预设的实际数值：慢 = 19 格/秒 · 笔长 22 · 停笔 55%；中 = 37 · 30 · 38%；快 = 73 · 45 · 18%。

### 4.5 解锁

| 功能 | 说明 |
| --- | --- |
| 显示全部世界 | 把隐藏 / 未解锁的世界在菜单里亮出来 |
| 解锁全部成就 | 触发世界与每一关的 Steam 成就 |
| 标记全部完成 | 把每张图标记成已完成 |

> DLC 拥有判定会被放行；仅供单机娱乐，请自行评估使用风险。

### 4.6 游戏设置

游戏设置里的开关与音量滑条镜像，改哪项立刻生效并写盘。顶部预设按钮：

| 按钮 | 作用 |
| --- | --- |
| 应用推荐预设 | 按内置推荐值一键套用（套用前自动记快照） |
| 撤销上次改动 | 回到「套用预设 / 恢复默认」之前 |
| 存为预设 | 把当前设置存成预设文件 |
| 套用自定义预设 | 加载之前存的预设文件 |
| 恢复游戏默认 | 回到游戏出厂默认 |

> 预设与快照存在 `%APPDATA%\ColoringVoxelsTool`，不随游戏目录清理。

### 4.7 其它全局行为

| 功能 | 说明 |
| --- | --- |
| 颜色高亮 | 高亮当前选中颜色的待涂体素（只处理当前层），<kbd>F6</kbd> 三档循环；颜色与不透明度可调 |
| 提醒与播报 | 倒计时到点弹窗 + 系统语音（可循环、文案可改）；累计有效涂色每满 1 小时的趣味横幅 |
| 单图计时 | 进关卡后首次落笔开始，涂满停表，发呆超过 20 秒不计入 |
| 等级与统计 | 两条独立经验线（自动绘图 / 人工辅助）、按天使用统计，存 `%APPDATA%\ColoringVoxelsTool`，等级只升不降 |
| 删除存档二次确认 | 游戏里点删除存档前再拦一次，确定键 2 秒冷静期 |
| 插件日志 | 写 `%APPDATA%\ColoringVoxelsTool\logs\plugin-yyyyMMdd.log`，按天一个、自动保留最近 7 份 |

> 人工辅助（屏幕扫描 + 模拟鼠标）这一整块仍在迁移中，3D 版暂不提供。

### 5.2 用户数据

等级、经验值与各项统计、单图计时、预设与快照、日志都存在**漫游目录**，不放在游戏目录里：

```
%APPDATA%\ColoringVoxelsTool\
├─ ColoringVoxelsTool.Profile.json        等级 / 经验 / 统计
├─ ColoringVoxelsTool.Times.txt           单图用时记录
├─ ColoringVoxelsTool.Stats.txt           按天使用统计
├─ ColoringVoxelsTool.Preset.txt          自定义游戏预设
├─ ColoringVoxelsTool.Preset.snapshot.txt 预设快照（撤销用）
└─ logs\plugin-yyyyMMdd.log               插件日志（按天一个，保留最近 7 份）
```

之所以不放游戏目录，是因为 `BepInEx\config` 会随「覆盖安装 / 卸载插件 / 验证游戏文件完整性 /
重装游戏」一起消失，放在那儿就会出现「更新一次版本，等级从头再来」。

- 等级拆成**两条互不相干的经验线**：`levelManual` / `xpManual`（人工辅助）与
  `levelAuto` / `xpAuto`（自动绘图）；只要经验值还在，等级就能反推还原，存档里等级字段丢了也不会掉级。
- `ColoringVoxelsTool.Profile.json.bak` 是上一份存档；`*.corrupt-*` 是读出来怀疑损坏、被挪走而非删除的存档。

## 7. 排错

| 现象 | 排查 |
| --- | --- |
| 按 F1 无反应 | 是否已进入关卡；检查 `BepInEx\plugins\ColoringVoxelsTool.dll` 是否存在；查看 `BepInEx\LogOutput.log` |
| 游戏启动即闪退 | 是否装错位数（插件仅支持 64 位主程序）；卸载后重装 |
| 一键涂完 / 拟人 / 自动化没反应 | 确认已进入关卡；拟人涂色是否已开始（<kbd>F3</kbd>）|
| 颜色高亮看不到 | 确认已选中某个颜色、<kbd>F6</kbd> 不是「关闭」档，且画布在当前视角内 |
| 安装器提示权限不足 | 用管理员身份运行 |
| 安装器提示游戏正在运行 | 关闭游戏后重试，或允许安装器结束进程 |
| 面板参数不生效 | 检查 `coloringvoxels.cheatsuite.cfg` 是否被锁为只读 |

日志位置：

- 插件日志（**排查问题优先看这份**）：`%APPDATA%\ColoringVoxelsTool\logs\plugin-yyyyMMdd.log`
  按天一个文件、带时间戳与级别，自动只留最近 7 份。
- 插件 BepInEx 日志：`<游戏目录>\BepInEx\LogOutput.log`（BepInEx 自己的输出，内容与上面基本重合）
- 安装器日志：`%TEMP%\ColoringVoxelsTool-Setup.log`
- 用户数据（等级 / 统计 / 预设快照 / 日志）目录：`%APPDATA%\ColoringVoxelsTool\`
  安装器「安装选项」卡片上直接写了这个路径，旁边有「打开」按钮可以直接跳到那里。
